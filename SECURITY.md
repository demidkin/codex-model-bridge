# Security Policy / Политика безопасности

## Русский

Если вы обнаружили уязвимость или случайно закоммиченный секрет (токен,
пароль, ключ), пожалуйста, **не создавайте публичный Issue**. Сообщите
приватно:

- через вкладку **Security → Report a vulnerability** в этом репозитории
  (GitHub Security Advisories), или
- на demidkin.spb@gmail.com.

Если утёк реальный секрет — считайте его скомпрометированным и ротируйте
его у провайдера независимо от того, удалили ли вы коммит.

## English

If you discover a vulnerability or an accidentally committed secret (token,
password, key), please **do not open a public issue**. Report it privately:

- via the **Security → Report a vulnerability** tab in this repository
  (GitHub Security Advisories), or
- at demidkin.spb@gmail.com.

If a real secret leaked, treat it as compromised and rotate it with the
provider regardless of whether the commit was removed.
