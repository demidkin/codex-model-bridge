# Contributing

Спасибо за интерес к проекту.

- Перед PR опишите проблему/предложение в Issue.
- Один PR — одно логическое изменение.
- Перед коммитом убедитесь, что не добавлены секреты/токены/пароли —
  репозиторий защищён CI-проверкой gitleaks, но лучше проверить локально.
- Следуйте стилю кода, уже принятому в проекте.

---

Thanks for your interest in the project.

- Open an issue before a PR to discuss the change.
- One PR — one logical change.
- Before committing, make sure no secrets/tokens/passwords are included —
  the repository is protected by a gitleaks CI check, but check locally too.
- Follow the existing code style.
