# Навыки Codex у DeepSeek и Claude

Адаптер автоматически получает **включённые** навыки из установленного Codex:
системные, пользовательские, проектные `.agents/skills` и навыки плагинов.
Копировать папки или переустанавливать навыки для каждой модели не требуется.
Отключённые пользователем навыки остаются отключёнными.

## Как начать

1. Полностью закрыть Codex через **⌘Q**.
2. Открыть существующий `bin/Codex Bridge.app`.
3. В AI Team Box создать **новую задачу**, выбрать DeepSeek и дать поручение.

Например:

> Используй подходящие навыки Codex для этой задачи. Если потребуется работа
> с фронтендом, соблюдай проектный навык claude-code.

> Через ImageGen создай иллюстрацию синего робота, поливающего цветок на Луне.

> Через bridge_agents запусти субагента на deepseek-flash. Пусть применит
> подходящий навык Codex для проверки документа и вернёт результат.

Навыки доступны как основной задаче, так и управляемым субагентам. Без явного
`model` субагент по-прежнему наследует модель родителя. Для работы с навыками
делегирование само по себе не требуется.

## Что изменилось

- В каталоге обеих моделей DeepSeek включено `include_skills_usage_instructions`.
- Каталог `skills/list` добавляется в инструкции внешнего исполнителя. Он
  включает описания, абсолютные пути и объявленные зависимости навыков.
- `bridge_skills.list_skills`, `read_skill`, `read_resource` позволяют получить
  актуальный каталог и прочитать инструкции/текстовые ресурсы. Выполнение
  скриптов остаётся у штатных инструментов с прежними разрешениями.
- Claude получает тот же каталог и SDK MCP `bridge_skills`. Нативное вложение
  Codex типа `skill` переводится в текст выбранного включённого навыка.
- Дочерние задачи наследуют переданные приложением `dynamicTools` и выбранные
  корни возможностей. Их схемы сохраняются в приватном реестре; ключи и
  произвольный конфиг родителя не копируются. Инструкции родительского диалога
  автоматически в другой диалог не переносятся.
- Инструкции самой задачи сохраняются отдельно, чтобы обновление каталога
  при resume не стирало правила вызывающего приложения. SQLite имеет версию 4;
  прежние маршруты, история и сессии сохраняются.

## Как работает ImageGen

`bridge_skills.generate_image` запускает специального помощника **Astra по
подписке ChatGPT**. Помощник вызывает настоящий встроенный ImageGen и
возвращает изображение. Основная задача остаётся на DeepSeek или Claude.
OpenAI API-ключ и CLI fallback не используются. Расходуются квоты подписки
на помощника и генерацию, а сообщения DeepSeek продолжают идти через его API.

Результат принимается только после нативного события `imageGeneration` со
статусом completed и существующим `savedPath`; одного заявления модели
«картинка готова» недостаточно. Поддерживается передача до пяти локальных
изображений по абсолютным путям; редактирование по референсу отдельно ещё
не проверялось. Отмена останавливает помощника, автоматического повтора нет.
Помощник учитывается в общем лимите субагентов: четыре активных на исходную
задачу, глубина три. Недоступность Astra/ImageGen возвращается как ошибка.

## Границы поддержки

Навык — это инструкции. Для навыка, которому нужен определённый MCP, аккаунт,
плагин или библиотека, соответствующая зависимость также должна быть доступна.
Наличие каталога не доказывает работоспособность каждого инструмента.
В Claude сохранены `--safe-mode` и `--strict-mcp-config`: его произвольные
сторонние MCP/hooks не подключаются. Через SDK добавлены только сервисы
адаптера `bridge_agents` и `bridge_skills`; универсального перевода всех
desktop-инструментов в Claude в этой версии нет.

Старые задачи OpenAI/DeepSeek не получают новые dynamic tools через resume:
установленный протокол их там не принимает. Для полного набора нужен новый
диалог. Правила старой задачи с неизвестными адаптеру developer instructions
не заменяются одним каталогом. Пересборка `.app` и повторный ввод ключей не нужны.

Для отключения этого расширения: `enable_skills = false` в `[bridge]`
`bridge.local.toml`, затем перезапуск. Для ImageGen также нужен включённый
`enable_agents`. Приложение автоматически не перезапускается.

## Проверки

В AI Team Box штатный Codex обнаружил 60 навыков, из них 20 включены,
включая `imagegen` и проектный `claude-code`: `skills-discovery.json`.
Файлы AI Team Box не изменялись.

Реальные DeepSeek main/child самостоятельно выбрали тестовый навык и прочитали
непредсказуемый код из его ресурса. Claude Sonnet по Max обработал явный skill
input и прочитал ресурс. DeepSeek Flash → Astra → ImageGen создал настоящий
PNG: `live-skills.json`. Первое сравнение пути Claude выявило различие
`/var`/`/private/var`, исправленное канонизацией пути.

`native-agents.json`: настоящий штатный движок с локальным имитатором API
подтвердил каталог в запросах родителя/ребёнка, вызов унаследованного инструмента
хоста и его ответ, включая перезапуск. `test-results.txt` содержит unit-проверки;
`stdio-agents.json` — запуск настоящей обёртки с отдельным состоянием.
**Это не визуальная приёмка основного окна.** Все навыки по отдельности,
карточки изображений/субагентов и ImageGen из Claude ещё не проверены в GUI.
